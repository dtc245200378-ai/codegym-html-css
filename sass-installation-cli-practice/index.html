Hướng Dẫn Cài Đặt SASS & SASS CLI

Thực hành biên dịch SCSS sang CSS sử dụng npm và SASS CLI

Các Lệnh SASS CLI Cơ Bản

  • Kiểm tra Node.js: node -v
  • Kiểm tra npm: npm -v
  • Cài đặt SASS Toàn Cục: npm install -g sass
  • Kiểm tra phiên bản SASS: sass --version
  • Biên dịch 1 tệp SCSS: sass scss/style.scss css/style.css
  • Bật chế độ Theo Dõi (Watch Mode): sass scss/style.scss css/style.css --watch
  • Theo dõi toàn bộ thư mục: sass scss/:css/ --watch
